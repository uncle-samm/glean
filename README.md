# glean

A Gleam framework for building AI agents. Think [pydantic-ai](https://github.com/pydantic/pydantic-ai), [Vercel AI SDK](https://github.com/vercel/ai), or [TanStack AI](https://github.com/TanStack/ai) — but for Gleam, running on the BEAM.

[![Package Version](https://img.shields.io/hexpm/v/glean)](https://hex.pm/packages/glean)
[![Hex Docs](https://img.shields.io/badge/hex-docs-ffaff3)](https://hexdocs.pm/glean/)

## Installation

```sh
gleam add glean
```

## Development

```sh
gleam run   # Run the project
gleam test  # Run the tests
```
